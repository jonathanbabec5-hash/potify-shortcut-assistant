# Shortcut Studio Pilot Marketing Plan

## Positioning

**For iOS Shortcuts power users and automation consultants:** Shortcut Studio is a preflight workspace that helps turn an automation idea into an inspectable, validated Shortcut export. The differentiator is not just generation; it is making unsupported actions and missing details visible before import.

## Initial audience

- Independent iOS developers and Shortcuts power users who maintain complex workflows.
- Small automation consultancies that prototype client automations and need a reviewable handoff.
- Developer educators who teach Shortcuts workflows and can evaluate the catalog and diagnostics.

## One measurable developer goal

**By day 30, five independent developers complete a clean install and the full offline workspace build.** Measure with opt-in self-report through a GitHub issue template or a short feedback form; record only pass/fail and environment versions, not source code, personal Shortcut files, or credentials.

## One measurable sales goal

**By day 45, secure one paid two-week pilot with an iOS automation consultancy.** A qualified pilot should name a real workflow-review use case, a responsible buyer, and an agreed success criterion before any customer data is used.

## Pilot execution

1. Publish the setup, limitations, and synthetic examples in this repository.
2. Invite developers to reproduce the build and file only redacted setup issues.
3. Demonstrate one synthetic workflow end-to-end: request, plan, validation findings, and export review.
4. For consultancy conversations, propose a time-boxed pilot using synthetic or customer-approved test inputs; never upload personal Shortcut files by default.
5. At the end of the pilot, compare the agreed review time and defect-catch criteria with the consultancy's baseline before proposing wider use.

## Channels and guardrails

Use GitHub documentation/issues, direct conversations with iOS automation consultancies, and relevant developer communities. RoutineHub is a cited ecosystem resource, not a commitment to publish there. This plan does not post to or change any social account. Do not make claims of Apple endorsement, complete iOS compatibility, or guaranteed error prevention.

## Decision rule

Continue only if the developer goal is met and the paid pilot has a named use case with an explicit privacy boundary. Otherwise, revise onboarding or positioning before adding spend or collecting more data.
